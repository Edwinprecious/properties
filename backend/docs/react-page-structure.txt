# Complete React Frontend Page Structure
## Real Estate Property Management System

---

## 📱 PUBLIC PAGES (No Authentication Required)

### 1. Home Page - `/`
**Purpose:** Landing page with overview and featured content

**Features:**
- Hero section with search bar
- Featured properties showcase
- Property categories (Rent, Sell, Land, Airbnb, Buy)
- Platform statistics (total properties, locations, users)
- Testimonials/Reviews section
- Call-to-action buttons
- Footer with links

**Backend API:**
- `GET /api/properties` (for featured properties)
- `GET /api/admin/dashboard/stats` (for statistics - if public)

---

### 2. Properties Listing Page - `/properties`
**Purpose:** Browse all available properties with filters

**Features:**
- Grid/List view toggle
- Search bar (by title, description, location)
- Filter panel:
  - Category (rent, sell, land, airbnb, buy)
  - Location dropdown
  - Price range (min/max)
  - Bedrooms count
  - Bathrooms count
  - Status (active, sold, rented)
- Sort options:
  - Price (low to high, high to low)
  - Date (newest first, oldest first)
  - Title (A-Z, Z-A)
- Pagination controls
- Property cards showing:
  - Image
  - Title
  - Location
  - Price
  - Category badge
  - Bedrooms/Bathrooms icons

**Backend API:**
- `GET /api/properties?category=...&search=...&min_price=...&max_price=...&bedrooms=...&bathrooms=...&sort_by=...&sort_order=...&page=...&per_page=...`

---

### 3. Single Property Details Page - `/properties/:slug`
**Purpose:** View detailed information about a specific property

**Features:**
- Image gallery/carousel with thumbnails
- Property title and price (prominent)
- Location with map icon
- Property details section:
  - Bedrooms, Bathrooms
  - Category, Status
  - Address
  - Square footage (if available)
- Full description
- Amenities/Features list
- Contact form/Inquiry section
- "Add to Favorites" button (if logged in)
- Share buttons (social media)
- Related/Similar properties section
- Breadcrumb navigation

**Backend API:**
- `GET /api/properties/slug/:slug`
- `GET /api/properties/slug/:slug/related`
- `POST /api/inquiries` (when user submits inquiry)
- `POST /api/favorites` (when user favorites property)
- `GET /api/favorites/check/:property_id` (check if favorited)

---

### 4. Properties by Location - `/properties/location/:location`
**Purpose:** View all properties in a specific location

**Features:**
- Same as Properties Listing Page
- Location name in header
- Pre-filtered by location
- Option to change location

**Backend API:**
- `GET /api/properties/location/:location`

---

### 5. Login Page - `/login`
**Purpose:** User authentication

**Features:**
- Email input field
- Password input field (with show/hide toggle)
- "Remember me" checkbox
- "Forgot Password?" link
- Login button
- "Don't have an account? Sign up" link
- Error messages display
- Success redirect to dashboard

**Backend API:**
- `POST /api/login`

**Response:**
```json
{
  "access_token": "...",
  "role": "user/admin/agent",
  "success": true
}
```

---

### 6. Signup Page - `/signup`
**Purpose:** New user registration

**Features:**
- Name input field
- Email input field
- Phone number input field
- Password input field (with strength indicator)
- Confirm password field
- Role selection (optional - user/agent)
- Terms & conditions checkbox
- Signup button
- "Already have an account? Login" link
- Email verification notice
- Success message

**Backend API:**
- `POST /api/signup`

**Request Body:**
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "phone": "1234567890",
  "password": "password123",
  "confirm_password": "password123",
  "role": "user"
}
```

---

### 7. Forgot Password Page - `/forgot-password`
**Purpose:** Request password reset

**Features:**
- Email input field
- Instructions text
- Submit button
- Success message ("Check your email")
- Back to login link
- Email sent confirmation

**Backend API:**
- `POST /api/forgot-password`

---

### 8. Reset Password Page - `/reset-password?token=...`
**Purpose:** Set new password using reset token

**Features:**
- Token validation on page load
- New password input field (with strength indicator)
- Confirm password input field
- Submit button
- Password requirements display
- Success message
- Redirect to login after success
- Invalid/expired token error handling

**Backend API:**
- `GET /api/verify-reset-token/:token` (verify token on load)
- `POST /api/reset-password` (submit new password)

## 🔐 USER PAGES (Authentication Required)

### 9. User Dashboard - `/dashboard` or `/user/dashboard`
**Purpose:** User's main control panel

**Features:**
- Welcome message with user name
- Quick stats cards:
  - Total favorites
  - Total inquiries
  - Inquiry status breakdown
- Recent activity timeline
- Quick action buttons:
  - Browse properties
  - View favorites
  - View inquiries
- Shortcut links

**Backend API:**
- `GET /api/user/profile` (user info)
- `GET /api/favorites` (count)
- `GET /api/inquiries` (count and status)

---

### 10. My Favorites Page - `/favorites` or `/user/favorites`
**Purpose:** View and manage saved properties

**Features:**
- Grid of favorited properties
- Each property card shows:
  - Image
  - Title, location, price
  - Date added to favorites
  - "View Details" button
  - "Remove from Favorites" button
- Empty state if no favorites
- Filter/sort options
- Search within favorites

**Backend API:**
- `GET /api/favorites`
- `DELETE /api/favorites/:property_id`

---

### 11. My Inquiries Page - `/inquiries` or `/user/inquiries`
**Purpose:** View inquiry history

**Features:**
- List of all inquiries sent
- Each inquiry shows:
  - Property thumbnail and title
  - Inquiry message
  - Date sent
  - Status badge (pending/responded/closed)
  - Property link
- Filter by status
- Sort by date
- View inquiry details modal
- Delete inquiry option

**Backend API:**
- `GET /api/inquiries`
- `GET /api/inquiries/:id`
- `DELETE /api/inquiries/:id`

---

### 12. User Profile Page - `/profile` or `/user/profile`
**Purpose:** View and edit account information

**Features:**
- Profile information display/edit:
  - Name
  - Email
  - Phone
  - Role (display only)
- Change password section
- Account statistics
- Delete account option (with confirmation)
- Update profile button
- Success/error messages

**Backend API:**
- `GET /api/user/profile`
- `PUT /api/user/profile` (to be added)
- `PUT /api/user/change-password` (to be added)

**Features:**

  - Bedrooms (number)

  - Square footage
  - Description (rich text editor)

  - Image preview
  - Drag-and-drop support

- Submit button
- Cancel button
- Success message with redirect

**Backend API:**
- `POST /api/admin/properties`

## 💡 TIPS FOR IMPLEMENTATION

1. **Start with routing:** Set up React Router with all routes first
2. **Create reusable components:** PropertyCard, Button, Input, etc.
3. **Set up authentication context:** Manage user state globally
4. **API service layer:** Centralize all API calls in service files
5. **Error handling:** Implement consistent error handling across the app
6. **Loading states:** Show loading indicators for async operations
7. **Form validation:** Use libraries like Formik or React Hook Form
8. **Responsive design:** Mobile-first approach with Tailwind CSS
9. **State management:** Consider Redux if app becomes complex
10. **Testing:** Write tests as you build features
